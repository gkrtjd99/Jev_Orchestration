# Api Doc Entries

Use when describing an endpoint that src/http already serves in docs/api.md: its path, its parameters and one example exchange.

## Steps

1. Copy the path and method from the route list, never from memory.
2. Show one example request and the answer it gets.
3. List the statuses the endpoint can answer with.
