# Settings Doc Wording

Use when rewording or reordering the entries of docs/settings.md for values that src/config already reads, without changing any behaviour.

## Steps

1. Keep one table line per value and keep each default value exactly as the code has it.
2. Do not touch src/config in the same change.
3. Ask a second reader whether the meaning column can be understood without the code.
