# Admin Console I18n

Use when extracting or translating interface strings of the staff admin web console, such as labels, buttons, menus and table headings.

## Steps

1. Wrap each visible string in the translate helper of the console.
2. Run the extraction script to refresh the catalog files.
3. Ask a native speaker to check plural forms.
