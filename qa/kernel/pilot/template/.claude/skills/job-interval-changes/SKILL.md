# Job Interval Changes

src/jobs에 이미 등록된 작업의 실행 주기(everyMinutes)를 바꾸거나, 그 작업을 한동안 꺼 둘 때 사용.

## Steps

1. 주기를 바꾸기 전에 그 작업이 한 번 도는 데 걸리는 시간을 확인한다.
2. 작업을 끌 때는 목록에서 지우지 말고 이유를 주석으로 남긴다.
3. 바꾼 주기를 docs/runbook.md에도 반영한다.
