# Gdpr Data Requests

Use when a customer exercises a privacy right, asking for a copy of the personal data held about them or for that data to be deleted.

## Steps

1. Verify the identity of the requester.
2. Answer within thirty days.
3. Record the request and its outcome in the privacy register.
