# Accessibility Audit

Use when checking a page of the staff web console for keyboard, contrast and screen-reader issues before it is released to building staff.

## Steps

1. Tab through the page without a mouse.
2. Check colour contrast of text and controls.
3. Run a screen reader over the main flow.
