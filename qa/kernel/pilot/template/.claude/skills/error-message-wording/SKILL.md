# Error Message Wording

Use when rewording the message text of an error that code under src/ already throws, so that front-desk staff can act on what it says.

## Steps

1. Say what happened and what the reader can do next, in that order.
2. Keep identifiers such as the parcel id in the text.
3. Search the tests for the old text and update them in the same change.
