# Dashboard Summary Columns

Use when changing the internal daily summary in src/reports that feeds the operations dashboard, such as adding a count or renaming a column.

## Steps

1. Change the summary module and its test in the same commit.
2. Tell the dashboard maintainers before a column is renamed or removed.
3. Keep one line per day; do not add per-parcel lines to the summary.
