# Flaky Test Quarantine

Use when a test under test/ fails intermittently on the build server and has to be isolated without hiding failures that are real.

## Steps

1. Reproduce it at least once locally or record that you could not.
2. Move it to the quarantine suite with a ticket link.
3. Review the quarantine list weekly.
