# Settings

Read once at start by `src/config/settings.mjs`.

| Variable | Default | Meaning |
|---|---|---|
| `PORT` | `8080` | Port the front proxy forwards to |
| `PARCELDESK_STORE_PATH` | `data` | Folder with the seed records |
| `PARCELDESK_LOCALE` | `ko` | Locale used when a customer has none |
| `PARCELDESK_CODE_TTL_HOURS` | `72` | How long a pickup code stays valid |
