# Financial model audit

1. Map sheets and the flow from inputs to outputs.
2. Flag constants inside formulas and rows where the formula pattern breaks.
3. Trace every circular reference and confirm whether it is intended.
4. Check that the balance sheet balances and cash reconciles in every period.
