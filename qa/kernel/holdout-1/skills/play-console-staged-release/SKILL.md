# Play 단계적 출시

1. 프로덕션 트랙에 1% → 5% → 20% → 50% → 100% 순서로 올립니다.
2. 각 단계에서 24시간 동안 ANR 비율과 크래시 비율을 확인합니다.
3. 기준을 넘으면 '출시 중단'을 누르고 원인을 조사합니다.
4. 비율을 바꿀 때마다 릴리스 채널에 기록을 남깁니다.
