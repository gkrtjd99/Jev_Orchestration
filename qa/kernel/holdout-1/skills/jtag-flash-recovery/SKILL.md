# JTAG/SWD 복구

1. 디버그 프로브를 연결하고 타깃 ID가 읽히는지 확인합니다.
2. 플래시 내용을 먼저 덤프해 백업합니다.
3. 부트로더, 파티션 테이블, 펌웨어 순서로 다시 기록합니다.
4. 기기별 캘리브레이션 영역은 지우지 않도록 주소 범위를 확인합니다.
