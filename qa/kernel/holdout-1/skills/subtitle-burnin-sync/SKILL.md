# 자막 싱크와 번인

1. 일정하게 밀리면 오프셋을, 뒤로 갈수록 벌어지면 프레임레이트 비율을 보정합니다.
2. 처음, 중간, 끝 세 지점에서 싱크를 확인합니다.
3. ffmpeg subtitles 필터로 입히고 글꼴과 여백은 스타일 프리셋을 사용합니다.
4. 원본 자막 파일은 따로 보관합니다.
