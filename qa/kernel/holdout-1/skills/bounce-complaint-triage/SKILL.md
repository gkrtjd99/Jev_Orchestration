# 반송·스팸 신고 급증 대응

1. 수신 사업자별(Gmail, 네이버, 다음 등)로 반송 코드와 신고율을 나눠서 봅니다.
2. 급증 시점 전후의 변경 사항(수신자 목록, 콘텐츠, 발송량)을 확인합니다.
3. 하드 바운스 주소는 즉시 제외하고, 신고율이 0.3%를 넘는 세그먼트는 발송을 멈춥니다.
4. 조치 내용과 회복 추이를 일 단위로 기록합니다.
