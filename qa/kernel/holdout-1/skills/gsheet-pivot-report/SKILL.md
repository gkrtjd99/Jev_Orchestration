# Google Sheets roll-up report

1. Reference whole columns or named ranges so new rows are included.
2. Prefer one QUERY or pivot per question; keep raw data untouched on its own tab.
3. Add a date control cell rather than hard-coding periods.
4. Protect the summary tab and note the refresh behaviour at the top.
