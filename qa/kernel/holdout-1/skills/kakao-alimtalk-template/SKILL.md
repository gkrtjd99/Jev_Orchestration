# 알림톡 템플릿

1. 알림톡은 정보성 메시지만 가능합니다. 할인, 쿠폰, 이벤트 문구는 넣지 않습니다.
2. 변수는 #{변수명} 형식으로 쓰고 변수만으로 이루어진 문장은 피합니다.
3. 버튼 이름과 링크가 본문 내용과 일치하는지 확인합니다.
4. 반려 사유별 수정 예시는 references/rejections.md를 참고합니다.
