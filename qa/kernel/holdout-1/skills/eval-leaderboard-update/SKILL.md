# 리더보드 등록

1. 평가 셋 버전과 체크포인트 해시를 반드시 기재합니다.
2. 시드 3개 이상의 평균과 95% 신뢰구간을 함께 올립니다.
3. 기준 모델과 동일한 평가 스크립트 커밋을 사용했는지 확인합니다.
4. `leaderboard submit` 명령으로 등록하고 채널에 링크를 공유합니다.
