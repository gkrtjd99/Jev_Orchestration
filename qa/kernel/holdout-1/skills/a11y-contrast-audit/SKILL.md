# Accessibility audit

1. List every text/background pair and compute contrast; body text needs 4.5:1, large text 3:1.
2. Tab through the screen and record focus order and any focus traps.
3. Check touch targets are at least 44x44 pt and every control has an accessible name.
4. Report findings as a table: location, criterion, severity, suggested fix.
