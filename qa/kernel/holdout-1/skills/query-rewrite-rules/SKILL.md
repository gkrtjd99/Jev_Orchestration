# Search query rules

1. Each rule has a match type (exact, phrase, contains), an action and an owner.
2. Redirects for navigational queries; pins limited to three per query.
3. Rules with an end date for campaigns.
4. Test in the rules sandbox and check for conflicts with existing rules.
