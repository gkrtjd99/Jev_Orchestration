# HS 코드 분류

1. 품목의 재질, 기능, 용도를 정리하고 통칙 1~6 순서로 분류합니다.
2. 6단위까지 확정한 뒤 수입국 기준 세번(8~10단위)을 확인합니다.
3. 적용 가능한 FTA 협정세율과 원산지 결정 기준을 확인합니다.
4. 분류 근거를 문서로 남기고 애매하면 품목분류 사전심사를 권고합니다.
