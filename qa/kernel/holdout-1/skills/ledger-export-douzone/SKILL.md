# 더존 전표 업로드

1. 계정과목과 거래처를 더존 코드로 매핑합니다(매핑표: mapping/accounts.csv).
2. 전표 단위로 차변과 대변 합계가 일치하는지 검증합니다.
3. 업로드 양식의 열 순서와 날짜 형식(YYYYMMDD)을 지킵니다.
4. 100건 단위로 나눠 업로드하고 오류 행은 따로 모읍니다.
