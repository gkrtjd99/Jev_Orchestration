# Korean Style Guide

## Guidelines

1. Default to polite informal (haeyo-che); never mix speech levels on one screen.
2. Say what happened and what the user can do next; no blame.
3. Follow the terminology list for product nouns and loanwords.
4. Avoid translationese: drop needless pronouns and passive constructions.
