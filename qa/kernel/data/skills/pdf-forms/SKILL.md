# Pdf Forms

## Guidelines

1. List the field names and types before writing anything; map data keys to fields explicitly.
2. Set checkbox/radio export values, not just appearance streams.
3. Embed a font that covers the data (CJK names) before flattening.
4. Keep an unflattened copy when the recipient still has to sign.
