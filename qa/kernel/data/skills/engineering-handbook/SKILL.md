# Engineering Handbook

## Guidelines

1. New repositories start from the service template and keep its top-level layout.
2. Add CODEOWNERS and register the service in the catalog before the first deploy.
3. Create the on-call rotation and runbook stub.
4. Everything else in the handbook is background reading.
