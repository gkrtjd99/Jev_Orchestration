# Release Notes

## Guidelines

1. Group by Added, Changed, Fixed, Removed; lead with what users notice.
2. Rewrite commit subjects into user language; drop internal refactors.
3. Breaking changes get a migration snippet.
4. Link each entry to its pull request.
