# Docx Redline

## Guidelines

1. Work on the document XML; insert w:ins / w:del runs with author and date instead of rewriting text.
2. Preserve existing formatting runs and numbering; never regenerate the whole file.
3. Reply to comments in-thread and leave them unresolved for the counterparty.
4. Verify the result opens cleanly in Word with all changes listed in the review pane.
